# 第一阶段｜Ψ-NN 个人复现与适用范围

更新：2026-10-22。本文是供 Windows 实验机与 Mac 阅读机共同使用的简明记录；数值来自本机单次固定种子运行，不能视作统计结论。实验机环境为 WSL Ubuntu 24.04、Python 3.12、PyTorch 2.11.0+cu128、RTX 5060 Laptop；Mac 暂不承担训练。

## 学习问题

论文方法链条为 **teacher PINN → student distillation → weight clustering → relation-aware reconstruction → structured Ψ-NN retraining**，即“教师网络 → 学生蒸馏 → 权重聚类 → 保留关系的网络重构 → 结构化网络重训”。聚类中心的直接替换只覆盖其中一部分，不能称为最终 Ψ-NN。

本阶段要回答三件事：原始 PINN 与显式物理约束能做到什么；蒸馏和聚类能否稳定提取结构；自动重构的收益是否足以抵偿额外复杂度。最终工程判断还需要项目特定的域外验证、运行成本与失效判据。

所有下表值均为**本机结果**，不是论文 Table 1 的数字。MSE (*mean squared error*，逐点评估平方误差均值) 与 relative L2 (*relative L2 norm*，误差向量的二范数除以真值二范数) 同时报出，防止把不同误差定义混用。Laplace、Burgers、Poisson 用 200×200 网格；Flow 用作者 CSV 的 20,486 个坐标点。

便于 Mac 查看或作图的精确数值见 [`psi-NN/metrics/phase1.csv`](../psi-NN/metrics/phase1.csv)、[`poisson_diagnostics.csv`](../psi-NN/metrics/poisson_diagnostics.csv) 和 [`flow_pilot.csv`](../psi-NN/metrics/flow_pilot.csv)；本机原始 checkpoint 与训练日志未纳入公开仓库。

### Laplace：解析解 `u(x,y)=x³−3xy²`，域 `[-1,1]²`

| 模型/阶段 | 可训练参数 | MSE | 相对 L2 | 解释 |
|---|---:|---:|---:|---|
| 教师，末步 | 609 | 4.298×10⁻⁷ | 0.001103 | 蒸馏起点 |
| 学生，末步 | 177 | 3.643×10⁻⁴ | 0.03211 | 小模型明显失精 |
| average 聚类中心直接替换 | 16 个中心 | 0.04965 | 0.3749 | 不是完整 Ψ-NN |
| Ward 聚类中心直接替换 | 18 个中心 | 0.05190 | 0.3833 | 不是完整 Ψ-NN |
| 普通 PINN，80k | 313 | 1.025×10⁻⁷ | 0.000539 | 比本次预写 Ψ-NN 弱 |
| PINN-post，80k | 313 | 2.298×10⁻⁸ | 0.000255 | 本次最佳 |
| 作者预写 Ψ-NN `d=8`，80k | 329 | 5.100×10⁻⁸ | 0.000380 | 优于普通 PINN，弱于 PINN-post；非自动发现 |

Laplace 配置采用 101×101 PDE 残差点、每边 101 个边界点、Adam 学习率 `1e-4`、固定种子 1234。教师在 60k 的独立 MSE `8.102×10⁻⁸`，反而好于 80k 末步，不可用中途最佳值冒充最终检查点。补充材料 Table 4 写 `d=8`，§4.1 写 `d=4`；在作者实现里 `d=8` 为 329 参数，多于基线 313，`d=4` 则为 101 参数。因此公平性与尺寸结论仍待 `d=4` 试验核对。

### Burgers 逆问题：20 个稀疏观测，Cole–Hopf 整域参考

| 模型 | MSE | 相对 L2 | 黏度估计 `ν` |
|---|---:|---:|---:|
| 普通 PINN | 0.007747708 | 0.1436813 | 0.00873974 |
| PINN-post | 0.000390531 | 0.0322583 | 0.00514002 |
| 作者预写 Ψ-NN | 0.000307625 | 0.0286302 | 0.00534154 |

目标黏度 `ν=0.01/π≈0.00318310`。作者预写 Ψ-NN 的场误差最低，但其黏度估计在这次运行中不如 PINN-post。学生权重聚类后进行的固定共享关系重训，MSE 为 `0.077770`，没有重现预写结构的性能；这一负结果应保留。原始 20 个观测来自作者仓库 `Database/Burgers_inv_data_1.csv` 与 `_3.csv`。

### Poisson：四频源项，域 `[0,1]²`

按作者训练代码的方程 `Δu=f`、零边界，`f=½Σₖ₌₁⁴(-1)^(k+1)k²sin(kπx)sin(kπy)`。因为 `Δ[sin(kπx)sin(kπy)]=-2k²π²sin(kπx)sin(kπy)`，与该 PDE 一致的解析解是 `u=-Σₖ₌₁⁴(-1)^(k+1)sin(kπx)sin(kπy)/(4π²)`。作者 `Training.net_global()` 的参考式却使用正号及额外的 `k` 系数；这两个场在 200×200 网格上的 MSE 为 `0.008576`。以下“解析解误差”以 **PDE 一致的解** 为准，另一式仅作为冲突核查，不拿它评价方法优劣。

`Poisson_REPRO` 仅把作者 `Poisson_EXP.csv` 的中间快照间隔改为 1,000 步：三模型各 30,000 步、101×101 个方程点、每边 101 个边界点、种子 1234、Adam 初始学习率 `10⁻³`，**没有衰减**。

| 模型 | 可训练参数 | 末步 MSE | 相对 L2 | 边界 MSE | 交换对称 MSE |
|---|---:|---:|---:|---:|---:|
| 普通 PINN | 1,381 | 6.147×10⁻⁵ | 0.3111 | 3.162×10⁻⁴ | 2.400×10⁻⁵ |
| PINN-post（显式 `x↔y` 对称） | 1,381 | 5.762×10⁻⁵ | 0.3012 | 2.768×10⁻⁴ | ≈0 |
| 作者预写 Ψ-NN | 2,161 | 9.277×10⁻⁷ | 0.03822 | 5.831×10⁻⁶ | ≈0 |

作者预写结构在这次运行中精度最高；但它比基线多 780 个参数（约 56%），不是等容量比较，也不是从本次蒸馏学生网络自动发现的结构。在第 9,000 步，它的解析解 MSE 为 `1.494×10⁻⁵`，普通 PINN 和 PINN-post 分别为 `4.434×10⁻⁴`、`2.436×10⁻⁴`；这反映早期趋势，不取代末步结果。[论文正文](https://www.nature.com/articles/s41467-025-64624-3)提到第 5,000、15,000 步的 0.2 倍学习率衰减，但仓库 `Poisson_EXP.csv` 没有相应字段，因此上表是**作者仓库配置**而非该正文调度。

这次三模型纯训练耗时约 460、765、746 秒（均不含出图）；结构模型在早期步数更准，不代表同硬件总训练成本更低。时间还受本机 RTX 5060 Laptop 与作者 RTX 4080 差异影响。

为核查上述差异，`Poisson_PAPER_SCHEDULE` 保持同一数据、网络、种子和 30k 步，仅把正文描述解释为 `MultiStepLR([5000,15000], gamma=0.2)`，即 `10⁻³ → 2×10⁻⁴ → 4×10⁻⁵`。两次运行前 5,000 步的 loss 逐项一致，说明起点可比；这仍只是对论文文字的一种明确实现，不能自称唯一官方配置。

| 模型 | 无衰减 MSE / 相对 L2 | 5k/15k 调度 MSE / 相对 L2 |
|---|---:|---:|
| 普通 PINN | 6.147×10⁻⁵ / 0.3111 | 9.129×10⁻⁵ / 0.3791 |
| PINN-post | 5.762×10⁻⁵ / 0.3012 | 8.948×10⁻⁵ / 0.3753 |
| 作者预写 Ψ-NN | 9.277×10⁻⁷ / 0.03822 | 2.655×10⁻⁶ / 0.06465 |

调度版的 Ψ-NN 在 18k 附近没有无衰减版的瞬时 loss 尖峰，但三个模型的末步解析解误差均更高。一次固定种子的结果只能证明“本机此配置下，曲线更平滑不等于场更准”；还不能推断学习率衰减普遍有害。完整数值、边界及对称误差见 [`poisson_diagnostics.csv`](../psi-NN/metrics/poisson_diagnostics.csv)。

### 圆柱绕流 Flow：仅 1,000 步/模型的 pilot

本次完整使用作者仓库 `Database/flow/fluid_data.csv` 的 20,486 个坐标作 PDE 配点，并以其中 `p/u/v` 字段作同域参考；内部字段不直接进入训练损失，但坐标参与训练，CSV 的生成来源也尚未核实。三模型均仅 1,000 步，作者 `Flow_EXP.csv` 为 200,000 步/模型；所以这里是训练链路和早期误差检查，**不是论文 Flow 结果复现，也不是工程域外验证**。

| 模型 | 参数 | `p` MSE / 相对 L2 | `u` MSE / 相对 L2 | `v` MSE / 相对 L2 |
|---|---:|---:|---:|---:|
| 普通 PINN | 3,523 | 0.7138 / 0.4949 | 0.2137 / 0.6441 | 0.03735 / 0.9673 |
| PINN-post（显式镜像对称） | 3,523 | 0.8194 / 0.5303 | 0.7751 / 1.227 | 0.05775 / 1.203 |
| 作者预写 Ψ-NN | 3,723 | 0.7044 / 0.4916 | 0.2116 / 0.6410 | 0.03618 / 0.9520 |

预写 Ψ-NN 此时只比普通 PINN 略好，所有场的误差仍大；PINN-post 虽严格满足 `p/u` 关于中心线为偶函数、`v` 为奇函数，却未带来更准的场值。较小的对称性误差可能只是预测接近常数／零，不能代替精度指标。圆柱压力边界项在最后一步仍约 `1.53`（三模型皆然），显示 pilot 尚未收敛。压力统一偏移修正后的 MSE 和对称性检查见 [`flow_pilot.csv`](../psi-NN/metrics/flow_pilot.csv)。

三模型纯训练耗时约 69、100、138 秒；以此短程速度直接外推 200,000 步并不可靠，因保存、出图、硬件负载和学习率阶段都会改变总耗时。

## 怎么读代码

| 文件 | 用途 | 建议阅读顺序 |
|---|---|---:|
| 上游 `Panel.py`、`Config/*.csv` | 选择算例、模型、步数与网格 | 1 |
| 上游 `Module/Training.py` | PDE 残差、数据损失、教师/学生训练 | 2 |
| 上游 `Module/PINN*.py`、`PsiNN_*.py` | 普通、硬约束与预写结构 | 3 |
| 自己的 `repro/run_train.py` | 无交互训练入口、固定种子 | 4 |
| 自己的 `repro/evaluate_*.py` | 独立误差评估 | 5 |
| 自己的 `repro/extract_structure.py`、`clustered_burgers.py`、`run_reconstructed.py` | 聚类、簇共享与受约束重训 | 6 |

`checkpoint` 是模型权重快照；`boundary condition` 是边界条件；`PDE residual` 是把预测代入方程后的残差；`hard constraint` 是直接在网络表达式中强制满足物理性质；`out-of-distribution` 指训练条件之外的参数、几何或边界。英文术语保留原文，方便与论文和源码逐词对照。

读新增算例时可沿着两条短链追踪：Poisson 的 `Config/Poisson_*.csv` → `Training.mesh_init()` 生成配点 → `net_f()` 计算 `Δu−f` → `net_b()` 约束零边界 → `evaluate_poisson.py` 用解析解独立评分。`net_global()` 虽然在源码中定义了另一参考式，但本次 Poisson 正问题的训练与出图均不调用它，不能把其中的式子当作本次 PDE 真值。Flow 的 `Database/flow/fluid_data.csv` 提供内部 *collocation points*（方程配点，只有坐标进入 PDE 损失）；`inlet/cylinder/wall/outlet` CSV 提供 *boundary data*（边界值）；`evaluate_flow.py` 对 `p`（pressure，压力）、`u/v`（velocity components，水平/竖直速度）评分。*Pressure gauge*（压力基准）意味着整体加一个常数也可能不改变压力梯度，所以另报移除平均偏移后的压力 MSE。

本机相对上游提交有可核查的 [`upstream-local.patch`](../psi-NN/patches/upstream-local.patch)：修复未配置学习率里程碑时的调度器错误，减少 Burgers 不使用的高阶导计算，缓存重复读取的观测 CSV，在蒸馏系数为零时跳过学生数据损失，并为绘图字体加入回退。这些改动与实验配置一起构成本次运行条件；不能把结果说成未经修改的上游代码输出。

## 本阶段可交付与工程门槛

当前可交付：可追踪配置、训练/评估脚本、单次实验数值、已知冲突和负结果。尚不具备“自动发现 Ψ-NN 可用于工程”的证据。下一步依次是：实现并验证跨层关系 `R` 的自动重构；对 Poisson 做等参数量、多随机种子与不同学习率调度比较；核实 Flow CSV 来源，并在明确算力预算后扩展至长程训练和未见坐标测试；在项目指定 PDE/几何/边界/噪声下测试迁移；最后与传统求解器和普通 PINN 比精度、训练成本、推理延迟及失败率。只有这些达标才讨论部署。
