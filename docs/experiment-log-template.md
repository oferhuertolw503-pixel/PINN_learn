# 实验记录模板

每个新实验复制本模板填写；失败实验也保留。先固定评价标准，再训练。

| 字段 | 本次填写 |
|---|---|
| 实验编号与日期 | |
| 研究问题/假设 | |
| 代码提交（本仓库与上游） | |
| 配置文件及相对路径 | |
| 数据来源、版本、训练/验证划分 | |
| PDE、几何、初边值、物理参数 | |
| 环境（OS、Python、PyTorch、设备） | |
| 随机种子与重复次数 | |
| 训练步数、优化器、耗时 | |
| 基线、参数量与模型选择规则 | |
| 独立测试网格/域外条件/噪声 | |
| 指标定义、单位与数值 | |
| 异常、失败和不确定性 | |
| 本机原始日志/权重位置（**不发布**） | |
| 可公开摘要/图表位置 | |
| 结论与下一项验证 | |

不要把训练 loss 当作整域误差；不要把“作者预写模型”的表现写成“本次自动发现结构”的表现。工程试验另外报告推理延迟、峰值内存、异常输入和失效比例。
