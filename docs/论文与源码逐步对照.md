## 1. 先抓住论文真正要做的事

普通 PINN 学一个解函数；本文还想从解函数中提取可重复使用的**参数关系**。

例如，某些权重应相同、某些应互为相反数、某些子矩阵应交换位置。固定这些关系，但重新训练关系内的自由参数，就得到结构化网络。

主线是：

```text
PDE + 边界/观测
       ↓ 物理损失训练
教师 PINN
       ↓ 教师预测作为监督；学生不再计算 PDE 高阶导数
学生 MLP + 参数正则化
       ↓ 权重/偏置取绝对值，逐层聚类，恢复符号
符号化参数矩阵
       ↓ 分析跨层共享、反号、排列关系
关系 R
       ↓ 保留关系，重新初始化可训练子参数
结构网络 Ψ-NN
       ↓ 使用 PDE 损失重新训练/迁移
比较 PINN、PINN-post、Ψ-NN 的误差与收敛
```

“网络结构发现”主要指参数共享与符号、排列模式的发现，不是从零搜索任意层数和宽度。文中的自动性也不意味着当前仓库有一个从 PDE 输入到新模型生成的一键程序。

重要边界：蒸馏拟合教师函数值，并不单凭这一损失就严格保证学生的 PDE 导数残差小；结构化网络可以严格保持某种对称性，也不等于自动严格满足全部 PDE、边界条件或任意守恒律。

## 3. 按补充材料 Algorithm 1，逐步对应

### Step 1.1：训练教师

论文：正文式 (48)–(50)，补充材料式 (1.8)/(1.11)，Algorithm 1 第 4–13 行。

1. **初始化函数近似器。** [PINN.Net](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PINN.py) 用 `Linear + Tanh` 构成 MLP，最后一层为线性输出。
2. **建立采样点。** `mesh_init()` 生成可求导坐标；这里的 `requires_grad=True` 是为了算 PDE 导数。
3. **计算物理损失。** [net_f](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/Training.py) 调用 `torch.autograd.grad(..., create_graph=True)`。先算解对坐标的导数，再对残差损失做参数反向传播。
4. **计算边界或观测损失。** [net_b](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/Training.py) 和 [net_d](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/Training.py)。正问题主要用前者；逆问题用后者。
5. **合成损失。** `train_adam()` 第 620–645 行：一般正问题为 `loss_f + loss_b`，逆问题为 `loss_f + loss_d`；Flow 另有边界权重。
6. **更新。** 第 647 行起执行 `backward`、`optimizer.step()`、`scheduler.step()`。

逆问题的未知 PDE 系数由 `para_undetermin` 表示，与网络参数一起交给 Adam。它是待优化变量，不是一个固定输入标签。

教师不加参数正则化的设置由 `regularization_state=0` 保证；程序本身支持打开，因此应核对配置，而不是假设教师总是没有正则化。

### Step 1.2：训练学生，即物理信息蒸馏

论文：正文式 (51)、(52)，补充材料式 (3.1)–(3.3)，Algorithm 1 第 14–23 行。

论文理想形式为：

\[
L_S = \operatorname{mean}[(u_S-u_T)^2]+\omega\Omega(\theta_S).
\]

对应位置：

- 学生实例：`train()` 第 928–929 行，重新建立普通 `PINN.Net(self.layer_student)`。
- 学生优化器：`train_adam()` 第 603–604 行，只包含学生网络参数。
- 教师输出拟合：[net_teach](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/Training.py)，最后返回 `mean((u_teacher-u_student)**2)`。
- 参数正则：[net_rgl](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/Training.py)。学生分支筛选名字含 `weight` 的参数。
- 学生循环：[train_adam 学生部分](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/Training.py)，依次算 `loss_student_d`、`loss_teach`、`loss_student_rgl`，再求和更新。

当前 Burgers 蒸馏配置的 `k_value=0`，所以 `net_d(mode='student')` 返回零；学生实际拟合教师并接受正则化，不再直接拟合观测值或 PDE。`k_value>0` 才启用补充材料讨论的观测融合分支。

教师在学生阶段没有 `detach()`，程序仍会为教师建立梯度并累积梯度，但学生优化器不包含教师参数，所以教师权重不会被学生优化器更新。这在结果含义上仍是固定教师，在资源使用上多做了无用反向传播。

**与公式的差异：** 实际正则项为 `1e-3 * Σ torch.norm(W, p=2)`。二维权重的该范数是 Frobenius 范数；代码没有平方，也没有按参数数量归一化，并且当前学生调用排除了 bias。它不等同于正文式 (52) 的平方 L2 和补充材料式 (3.2) 的平均平方参数。要严格复现实验，必须先决定以论文公式还是公开实现为准。

### Step 3：结构重建与重新训练

论文：正文 Network reconstruction、Algorithm 1 第 32–36 行。概念上可写成：

\[
\operatorname{vec}(W_l)=R_l a_l,
\]

其中 `R_l` 固定共享、反号、排列关系，`a_l` 是重新初始化后可训练的自由参数。这里用该式解释关系约束，不声称源码直接创建了一个同名矩阵。

实际仓库以 [PsiNN_laplace.py](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PsiNN_laplace.py)、[PsiNN_burgers.py](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PsiNN_burgers.py)、[PsiNN_poisson.py](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PsiNN_poisson.py)、[PsiNN_flow.py](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PsiNN_flow.py) 表达最终结构。

同一个 `nn.Linear` 在多个分支重复调用，就相当于固定相同参数关系；分支加减号表达符号关系；调换分支输入表达排列关系。这是把 R 隐含在程序连接关系中。

`train()` 重新调用这些类的构造函数，默认得到新初始化参数。这个动作对应“保留结构，重初始化数值”；之后继续用 `net_f()` 与边界/观测损失训练。它不是把聚类中心数值直接当作最终模型继续训练，也不是无需再训练就迁移。

## 4. 用 Laplace 走通论文与代码的数学关系

论文正文式 (1)、(2)：

\[
u_{xx}+u_{yy}=0,\quad (x,y)\in[-1,1]^2.
\]

补充材料给出的真解为 `u=x³−3xy²`。因此 `u(x,-y)=u(x,y)`，即关于第二坐标的偶对称。

1. **方程残差。** `net_f()` 的 Laplace 分支计算 `mean((u_xx+u_yy)**2)`。
2. **边界值。** `net_b()` 第 283 行起构造四条边；Laplace 分支使用该多项式边界值。PDE 残差限制内部调和性，边界项选择具体解。
3. **普通 PINN。** `PINN.py` 任意权重不保证偶对称，训练只能促使输出逼近真解。
4. **PINN-post。** [PINN_post_plus.forward](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PINN_post_plus.py) 输出 `f(x,y)+f(x,-y)`，交换 y 的符号后两项互换，所以偶对称严格成立。
5. **结构网络。** 读取 `PsiNN_laplace.forward()` 第 51 行起，按以下中间变量理解。

令 `a=fc1_2(x)`，`b=fc1_4(y)`。`fc1_4` 没有 bias，因此 `b(-y)=-b(y)`。

\[
h_+=\tanh(a+b),\quad h_-=\tanh(a-b).
\]

所以 y 变号时 `h_+`、`h_-` 交换。

第二层：

\[
q_+=\tanh(A(h_+)+B(h_-)),\quad
q_-=\tanh(B(h_+)+A(h_-)).
\]

这里 A、B 是代码中的两个共享仿射模块，y 变号后 `q_+`、`q_-` 也交换。第三层计算：

\[
r=\tanh(C(q_+)+C(q_-)),\quad u=D(r).
\]

交换 q 后其和不变，最终输出也不变。这直接对应正文式 (14)–(16) 所强调的对称机制。

注意：代码中多次调用带 bias 的仿射模块时，bias 也会被重复相加；因此上述式子保留仿射模块记法，而没有冒称其逐项数值恰好等于论文展示的每一个子矩阵。核心共享与交换机制对应，但并非字面相同的矩阵参数化。

**可立即验证的结论：** 不训练也能验证结构的偶对称；这正是“将物理性质写入结构”的含义。随机参数测试中最大差值为 0；求解 PDE 的精度仍需训练。

## 5. 其余算例分别对应什么

### Burgers：逆问题、奇对称与系数迁移

正文式 (17) 与 (18)–(26)，Fig. 7；配置是 `Burgers_inv_EXP.csv` 与 `Burgers_inv_distill_EXP.csv`。

代码的第一坐标 `self.x` 在该残差里承担时间 t，第二坐标 `self.y` 承担空间坐标。实际残差为：

\[
u_t+u u_x-\lambda u_{xx},
\]

也就是程序 `u_x + u*u_y - self.para_undetermin[0]*u_yy`。正文式 (17) 印的是 `u_t-u u_x-λu_xx`，非线性项符号与代码不同；补充材料同样使用负号。不能仅用坐标重命名解释该差异，需要核查数据生成约定。

代码 CSV 的第二坐标范围为 [0,1]，正文空间域写 [-1,1]。逆问题另读观测数据，不应把训练网格配置当作已覆盖全文空间域。

结构实现中 `fc1_1(t)±fc1_3(x)` 构成镜像分支；第二层有交换分支与差分支；第三层通过相减构造奇函数特征。这对应式 (18)–(26) 的共享、交换、反号思想。

**实际偏差：** [PsiNN_burgers.py 第 31 行](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PsiNN_burgers.py) 注释说去掉输出 bias，但 `nn.Linear(..., output_num)` 没写 `bias=False`。隐藏特征是奇函数时，最终输出仍是 `odd(x)+b`，从而：

\[
u(t,x)+u(t,-x)=2b.
\]

随机参数验证的最大奇对称误差约 0.03434，减去 `2b` 后约 `2.24e-8`。因此源码的最终输出不具有对任意权重都成立的严格奇对称。它仍可通过训练把 b 学到接近零，但那是训练结果，不是结构保证。

正文不同黏度之间迁移的是结构，并重新求解未知黏度；不是一个不重新训练就可预测全部黏度的现成代理模型。当前默认观测序号为 `1,3`，要对应 Fig. 7 三个实验，应分别核对各文件内容与黏度，不可默认一个入口已复现三组设置。

### Poisson：从简单结构迁移到多频解

正文式 (27)–(42)。代码 `net_f()` 使用：

\[
f=\tfrac12\sum_{k=1}^{4}(-1)^{k+1}k^2\sin(k\pi x)\sin(k\pi y),
\]

这与正文式 (28) 的 `1/4 × 2` 系数相同；残差为 `u_xx+u_yy-f`。

正文的结构发现起点是低频函数 `x₁²−x₂²`，随后调整符号以匹配交换对称的高频解。当前仓库没有对应的低频蒸馏配置；`net_global()` 中含 `lf` 的分支使用两个正弦乘积之和，也不是该二次多项式。不能把这个分支直接标成正文低频发现过程的完整实现。

最终 [PsiNN_poisson.forward](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PsiNN_poisson.py) 的机制很清楚：

1. `fc1(x)` 和 `fc1(y)` 使用同一个模块；
2. 第二层交换两输入并复用 `fc2_1`、`fc2_2`；
3. 下一层对两交换分支使用同一个 `fc3` 后相加；
4. 因此 `u(x,y)=u(y,x)`。

这对应正文式 (38)–(41) 的最终交换结构，而不是已演示式 (31)–(37) 到它的自动变换。随机权重测试交换误差为 0。源码的结构也不自动保证齐次 Dirichlet 边界；边界仍通过损失训练。

### Flow：复用结构，而非重新发现全部流动物理

正文式 (43)–(47)，Fig. 8。

`net_f()` 第 345–375 行将网络输出拆成 **p、u、v**，分别计算：

\[
u_x+v_y,
\quad \rho(uu_x+vu_y)+p_x-\mu\Delta u,
\quad \rho(uv_x+vv_y)+p_y-\mu\Delta v.
\]

参数为 `ρ=1`、`μ=0.02`，与补充材料一致。`net_b()` 读取入口、圆柱、壁面、出口 CSV；纵坐标统一减 0.2，将通道中线平移到 y=0。

程序除速度边界外默认还使用圆柱压力数据的监督项；这是读图时需要知道的额外数据来源。优化目标使用 `loss_f + bcs_weight*loss_b`，Flow 默认边界权重为 2，但保存的 `loss` 列由前面的 `loss_f + loss_b` 构造，因此日志总损失与真正优化的加权目标并非同一数值。

[PINN_post_flow](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/Module/PINN_post_flow.py) 显式让 p、u 为偶函数，v 为奇函数。

`PsiNN_flow.py` 组合一个差分特征分支和一个求和特征分支，最后 `fc4_1` 把两类特征自由混合成三个输出。该连接有结构共享，但**最终自由混合层并未强制每个输出选择其对应的奇/偶特征**，且输出层保留 bias。随机参数测试中 p/u 偶对称最大误差约 0.2205，v 奇对称误差约 0.3500。

所以不能声称这个类对任意参数都保证 p/u/v 的各自对称性。连续性方程也由 `loss_f` 施加；代码没有把速度表示成流函数导数来结构性保证无散度。非零测试仅否定“无条件保证”，并不说明训练后必然拟合失败。

## 6. 论文设置与仓库配置：哪些不能直接对号入座

| 项目 | 论文/补充材料 | 当前仓库 | 影响 |
|---|---|---|---|
| Laplace 发现阶段 | 教师 [16,16,16]；学生 [8,8,8] | 无对应发现配置 | 需补配置，不能用比较实验代替 |
| Laplace 比较基线 | [8,16,8] | [8,8,16] | 网络不同 |
| Burgers 发现阶段 | 教师 [16,16,16]；学生 [8,8,8] | [10,10,20]；[10,10,10] | 网络不同 |
| Burgers 比较基线 | [10,20,10] | [10,10,20] | 网络不同 |
| Poisson 比较基线 | [40,40,20] | [40,20,20] | 参数规模不同 |
| Poisson 边界点 | 每边 101 点 | `net_b()` 强制改为每边 1000 点 | 训练成本与离散边界监督不同 |
| Poisson 比较学习率 | 正文 1e-3，5000/15000 步乘 0.2；补充材料表 4 写 1e-4 | `train_adam()` 强制 1e-3，配置没有 milestone | 论文内部及代码之间均需厘清 |
| 学生正则 | 平方 L2，补充材料还含归一化 | 范数之和，未平方，学生仅 weight | 梯度方向和强度不同 |
| 关系 R 自动构造 | Algorithm 1 第 31 行 | 未提供通用桥接程序 | 完整结构发现不能一键运行 |
| L2 误差 | 补充材料 4.1 定义为全场均方误差 | 原绘图流程并非完整统一数值评估器 | 应明确 MSE、RMSE、相对 L2 各自定义 |

本机对当前代码统计的参数数：Laplace 的 PINN 257、结构网络 329；Poisson 的 PINN 1381、结构网络 2161；Flow 的 PINN 3523、结构网络 3723。**当前默认配置下不能直接套用“结构模型参数一定更少”的论文比较结论。** 这不否定共享本身减少冗余，而是说明比较宽度、有效节点数和配置必须对齐。

另一个实现成本：`net_f()` 的非 Flow 分支无论方程需要与否，都计算 `u_yyy`，Laplace/Poisson 实际不使用它；`net_d()`、Flow 边界函数每步重新读 CSV；训练中大量使用 `retain_graph=True`。这些会影响速度，但本次保持原始实现，未把优化后速度当作作者源码速度。

## 7. 这台 Mac 能做什么：以实测为依据

硬件：MacBook Air，Apple M5，10 核 CPU（4 性能核 + 6 能效核），8 核 GPU，16 GB 统一内存。系统 macOS 26.6，检查时可用磁盘约 385 GiB。

本地建立项目 `.venv`，Python 3.12.14、PyTorch 2.14.1。它与作者推荐的 Python 3.11.3/CUDA 11.7 不同；这是可运行环境验证，不是原版环境的逐项复制。原仓库只检测 CUDA 与 CPU；适配脚本通过设置 `Training.device` 测试 MPS。

实测说明：沙箱内 MPS 检测返回 false；在能访问系统 GPU 的进程中检测为 true，并成功运行原 Laplace 高阶导数训练。不能把前者误解为硬件不支持 Metal。

| 案例 | 短程验证 | 已证明 | 未证明 |
|---|---|---|---|
| Laplace | CPU 三模型各 100 步；MPS 三模型各 20 步；均保留 10201 配点 | PDE 高阶自动微分、优化和模型保存可执行 | 8 万步后达到论文精度 |
| Burgers 蒸馏 | CPU 教师 20 步、学生 40 步 | 逆问题、未知系数优化和蒸馏分支可执行 | 得到论文聚类结构及黏度估计 |
| Poisson | CPU 三模型各 20 步 | PDE 与边界损失训练可执行 | 多频解的论文精度 |
| Flow | CPU 三模型各 5 步，20486 内部点 | 三输出 NS 残差训练可执行 | 20 万步收敛、长期资源稳定和论文流场误差 |

短程 CPU 测得平均每步：Laplace PINN 7.25 ms、PINN-post 14.64 ms、Ψ-NN 15.64 ms；Flow 分别约 77.8/139.5/161.0 ms。不同算例短测曾并发进行，且未做严格的热稳态基准。

仅线性外推当前配置：Laplace 三组 8 万步训练时间合计约 **50 分钟**；Flow 三组 20 万步合计约 **21 小时**。这些是短测外推，不含原版频繁中途保存/绘图的完整开销，也不保证持续运行的温度、调度、资源变化下维持同速。

Flow 短测进程峰值 RSS 约 1.81 GiB；这是进程 CPU 驻留内存指标，不是长期总占用，也不是 Metal 显存峰值。16 GB 对这些小型网络的短程验证已有余量，完整运行仍应串行监测。

当前 Laplace 小网络上，MPS 短测每步约 30–114 ms，没有显示比 CPU 更快；20 步还包含预热，不能据此对所有算例判定 GPU 性能。实际学习和调试优先用 CPU 即可。

结论：**这台 Mac 可以执行公开算例，适合学习源码和分阶段实验；暂不能承诺复现论文数值。最主要的未决问题是配置差异和结构发现流程未连通，而不是 Mac 不能运行 PyTorch。**

## 8. 本地文件与可执行入口

- 原始仓库：[Psi-NN](https://github.com/ZitiLiu/Psi-NN/blob/2c11ce6df1bcfcf630d05f162d5795d7fa4fdb43/README.md)。历史短程检查保留了作者可执行逻辑；本次另以补丁发布中文注释，不改写原始实验配置或 notebook。
- 本机运行封装：[run_mac.py](../psi-NN/repro/run_mac.py)。逐模型运行，可指定 CPU/MPS、步数、配点；只关闭绘图和中途频繁保存，保留最终参数、损失、统计。
- 结构性质核对：[check_structure.py](../psi-NN/repro/check_structure.py)。随机初始化即可检查哪些对称性由结构保证。
- 核对结果：[structure_checks.json](../psi-NN/metrics/mac-smoke/structure_checks.json)。
- 实测日志和 checkpoint：`psi-NN/metrics/mac-smoke/`（只同步 summary，不含 checkpoint）；每个案例有 `summary.json`。summary 记录实际覆盖参数；旁边复制的原 CSV 只是作者原配置，短程步数以 summary 为准。

在项目目录执行短程验证：

```bash
python psi-NN/repro/run_mac.py --case Laplace --device cpu --steps 100 --tag learning
python psi-NN/repro/check_structure.py
```

要读懂核心机制，建议依次读第 4 节 Laplace 的分支交换证明、第 3 节的教师/学生损失、第 3 节的聚类与 R 缺口，最后再看 Burgers/Poisson/Flow 的迁移。后续若开展精度复现，应复制一套与论文逐项对齐的配置，并保留当前原始版本作为对照，分别报告误差定义、训练种子、配置、后端、步数和总成本。
